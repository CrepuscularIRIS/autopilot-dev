# Advisor contracts

Default PTC: Wish → Worker + asynchronous Flash proposal engine → optional long-horizon Kimi → one independent Lite code review. The Worker owns implementation, tests, and final Goal status. Advice never changes user authorization or proves verification.

consult_task({question: "...", entry: "rework"}) is optional for a significant fork or repeated failure. advisorRoute: "investigate", entry: "rework" opens an independent read-only investigation. advisorRoute: "review", scope: "general" invokes a single independent final review; review reports issues, not fixes. User choices use the native ask_user_question. Routine verify and image analysis stay with Worker; historic advisor_stage is available only through explicit legacy compatibility.

Model/provider role mapping is configured in the profile; see [example](../examples/profile.patch.yml). See [background workflow and optional knowledge](META-SUPERVISOR.md).
