# Autopilot Dev runtime

See the [installation guide](../README.md) and [advisor contract](ADVISOR.md). This package preserves the original Wish Specializer bundle identity. The bundle attaches to native DSH modes; use **PTC** for the full development workflow. No custom preset is required.

The optional Bash runtime is not bundled. The host's built-in shell and system shell remain available as configured. Use the Options panel to control the pre-send explainer, assistance, Advisor, context and permitted reads independently.
